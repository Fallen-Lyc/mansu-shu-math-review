# 讲评内容撰写规范（写每题内容前必读）

课件好不好，八成看这里。**这是唯一需要在 Step 2 前读完的参考文档**，其余按需再查。

## 0. 简写输入（省时间，脚本自动补）

- **不写 `spans`**：脚本按标点自动切分——带数字/单位的段标 `cond`，问句标 `ques`，
  出现图形名标 `fig`。切得不满意再手写覆盖。
- `mistakes`：写字符串数组，如 `["8+5=13（厘米），只加了一条长和一条宽"]`。
- `solutions.steps`：写算式字符串数组，如 `["S = a × h", "= 12 × 8", "= 96（平方厘米）"]`；
  需要多行讲解时用对象 `{ "label": "脱式", "lines": [...] }`。
- `solutions` / `variants` 都可直接写字符串或字符串数组。
- 完整字段写法见下，两种形式可混用。

## 1. 总原则

- **说人话**：对象是小学生。"本题考查学生的灵活运用能力"→"这道题考的是：合起来乘和分开乘，结果一样"。
- **讲道理不报步骤**：每步都回答"这一步在求什么"。
- **先防错再解题**：易错点在解题之前讲。
- 不出现"掌握/培养/提高/素养"这类教案腔。

## 2. 维度一：条件与问题（`spans`）

| kind | 用在哪 | 页面样式 |
|---|---|---|
| `cond` | 条件：给定的数、量、关系 | 蓝色横线 + ①②③ |
| `ques` | 问题：求什么 | 红色横线 |
| `key` | 关键限定词（正好、还剩、至少、平均、各） | 黄色横线 |
| `fig` | **图形名称**（正方形、三角形、圆…） | 橙色横线 + 上方小图形示意 |
| `none` | 连接词与叙述 | 不标 |

**硬要求：题干提到"是什么图形"，那个名称必须单独切成 `fig` 片段**（带后缀也照标："正方形石砖"）。
不提图形的题不标 `fig`。

- 条件切到"能拿来算"的粒度；**数和单位一起切**（"长是8厘米"整体一个 cond）。
- 3~6 个片段为宜：整段标 `none` 等于没做；逐字标会糊成一片。
- 切完自检：把所有 `cond` 连起来能复述题目给了什么，`ques` 连起来就是所求。

## 3. 维度二：分析四格（`analysis`）

四格固定，缺一格补一格，不合并、不加第五格；**每格 ≤ 30 字**。

| 字段 | 回答什么 | 示例 |
|---|---|---|
| `exam_point` | 考什么 | "考的是长方形周长的计算方法" |
| `key_conditions` | 哪些是必须用的条件 | "长8厘米、宽5厘米是求周长必须知道的两个条件" |
| `relation` | 条件怎么连 | "长方形有2条长和2条宽，围成一圈才是周长" |
| `quantity_relation` | 数量关系 | "周长 =（长 + 宽）× 2"（必须是关系式，不是算式结果） |

## 4. 维度三：易错点（`mistakes`，每题 1~2 条）

每条三要素：`wrong`（真实具体的错答）+ `reason`（思维漏洞）+ `fix`（可执行的改法）。
写成一句话也可以（错例 + 原因），等多种坑见 `03-知识点与错因速查.md` §6。

```
✗ reason: "粗心"        ✗ fix: "要认真"        ✗ 只写 wrong 不写原因
```

## 5. 维度四：解决问题（`solutions`）

**步骤标签写"求什么"，不写"第几步"**：✓ 一共 / 还剩 / 每条边 / 周长 / 单价；✗ 第一步 / 列式。

- 算式步骤：`{ "label": "周长", "expr": "（8 + 5）× 2", "value": "26", "unit": "厘米" }`
  → 页面 `[周长] （8 + 5）× 2 = 26（厘米）`
- 多行讲解/脱式：`{ "label": "脱式", "lines": ["24 × 3 − 28", "= 72 − 28", "= 44（盒）"] }`
- **单位换算不列进率算式**，直接写对应关系，进率只在 `note` 点一句：
  `✗ {"expr":"120000 ÷ 10000"}`　`✓ {"expr":"120000平方米","value":"12公顷","note":"平方米换公顷，除以10000"}`
- 方法**最多两种**，第二种要真的换了思考路径（公式法/分步法、画图法/算术法）。
- `answer`：完整答句带单位——"答：它的周长是26厘米。"

## 6. 维度五：变式（`variants`，须用户确认才做）

换数据｜换情境｜反过来问（已知未知互换）｜加一层（多一问）。
每条：`{ "stem": …, "hint": …, "answer": … }`，`hint` 给思路不给答案，一题最多 3 条。
变式需要配图时挂 `image_path`（不挂则沿用原题的逻辑，通常不复用原图，避免数字矛盾）。

## 7. 语言细节

运算符用 `×` `÷`；括号全角 `（ ）`；数字与单位不留空格（`26厘米`）；分数写 `3/4`。

## 8. 交付前自检

- [ ] 条件标了 `cond`、所求标了 `ques`，有图形名的标了 `fig`
- [ ] `analysis` 四格齐全 ≤ 30 字，`quantity_relation` 是关系式
- [ ] `mistakes` 每条都有错例 + 原因
- [ ] 每个 `label` 写的是"求什么"
- [ ] 综合算式用了 `lines` 脱式；方法 ≤ 2 种
- [ ] `answer` 带单位、答句完整
- [ ] 全篇没有教案腔
