# 知识点与错因速查

写 `knowledge` / `quantity_relation` / `mistakes` 时查这里。
**以试卷为准，以本表为辅**：卷面信息与本表冲突时听卷面的。

## 1. 数量关系（直接套）

- 部分 + 部分 = 总数；总数 − 部分 = 另一部分
- 大数 − 小数 = 相差数；每份数 × 份数 = 总数
- 总数 ÷ 每份数 = 份数；总数 ÷ 份数 = 每份数；一倍数 × 倍数 = 几倍数
- 单价 × 数量 = 总价；速度 × 时间 = 路程；工效 × 工时 = 工作总量
- 平均数 = 总数量 ÷ 总份数
- 和倍：和 ÷（倍数+1）= 一倍数；差倍：差 ÷（倍数−1）= 一倍数
- 归一：总数 ÷ 份数 = 单一量；归总：单一量 × 份数 = 总数

## 3. 单位换算（写到 `note` 或 `analysis`，不要写成算式）

- 长度：1 km = 1000 m；1 m = 10 dm = 100 cm = 1000 mm
- 面积：1 km² = 100 公顷 = 1000000 m²；1 公顷 = 10000 m²；1 m² = 100 dm² = 10000 cm²
- 体积容积：1 m³ = 1000 dm³；1 dm³ = 1000 cm³；1 L = 1000 mL；1 dm³ = 1 L；1 cm³ = 1 mL
- 质量：1 t = 1000 kg；1 kg = 1000 g
- 时间：1 时 = 60 分；1 分 = 60 秒；1 日 = 24 时；平年 365 日、闰年 366 日
- 人民币：1 元 = 10 角 = 100 分

## 5. 讲法年段差异

| 内容 | 低年级说法 | 高年级说法 |
|---|---|---|
| 平均分 | "每份分得同样多" | "总数 ÷ 份数 = 每份数" |
| 倍数 | "2个这么多" | "一倍数 × 倍数 = 几倍数" |
| 周长 | "围一圈有多长" | "C = 2(a+b)" |
| 面积 | "铺满要多少个小方格" | "S = ah" |
| 分数 | "把一个蛋糕平均分成4份，取1份" | "分数与除法：a ÷ b = a/b" |
| 方程 | （不出现） | "把未知量设为 x，找等量关系" |

核心素养只可在"考什么"里点一句，不要堆：数感、量感、符号意识、运算能力、几何直观、
空间观念、推理意识、数据意识、模型意识、应用意识、创新意识。

## 6. 错因库（每条 mistakes 都要 wrong + reason + fix）

**审题类**：漏条件（"只用了长，没用宽"）｜看错数字（"抄数时数位颠倒"）｜漏看限定词
（"没看到'平均'，直接求了总数"）｜单位没统一（"米和厘米直接相加"）｜问题理解偏
（"把'多多少'看成'一共多少'"）｜一题多问漏答

**概念类**：周长/面积混淆｜体积/表面积混淆｜倍数关系弄反｜份数与每份数弄反｜
分数大小比较错（"以为分母大的就大"）｜正反比例判错｜单位换算方向错（"大单位换小单位要乘进率"）

**运算类**：进位退位漏 1｜运算顺序错｜去括号没变号｜小数点位数错｜通分错｜
除数被除数颠倒｜余数大于除数｜整十数漏 0

**策略类**：不会找中间量（"缺了先求一共这一步"）｜数量关系不清｜不会画图｜代错数据｜不检验

**表达类**：漏单位｜答句不完整｜单位写错（面积写成"厘米"）｜该取近似值没取

**红线**：reason 不许写"粗心/不认真"；fix 必须是可执行的动作（圈、画、查、代回检验）；
宁可写"最容易卡在哪一步"，也不要编学生不会犯的错。

句型：高年级"错例 {wrong}，说明 {reason}。正确思路是 {fix}"；
低年级"有同学这样写：{wrong}。错在{reason}。记住：{fix}"。
