# 输入解析：从卷子到 questions.json

目标：把一张卷子（图片 / Word / PDF / 粘贴文本）变成 `questions.json`。
字段见 `../schema/questions.schema.json`，样例见 `../assets/sample_questions.json`。

## 1. 读图顺序（一次读完，不要反复读同一张图）

1. **全局**：卷名、年级班级、大题分区、题号分布。
2. **题型**：填空 / 选择 / 判断 / 计算 / 操作 / 解决实际问题——题型决定讲评写法。
3. **逐题精读**：题干全文、数据、单位、问题句、图意。
4. **校验**：把读出的题干心里念一遍，确认没漏数字、没漏"不"字、没漏单位。

### 易误读清单

| 陷阱 | 处理 |
|---|---|
| 手写答案/批改痕迹 | 只取印刷题干；可辨认的答案可用来推断典型错法 |
| 相似字形 6/8、0/6、1/7、3/5、+/÷ | 结合语境判断；确不了就在 `analysis` 注明"若原题为…则…" |
| 单位被裁掉 | 上下文补全，并在 `mistakes` 提醒单位 |
| "约""保留两位""至少" | 易错信号词，`spans` 里标 `key` |
| 表格行列错位 | 按行/列重述一遍再写 `stem` |
| 一题多问（1）…（2）… | 优先拆成两题 |

### 题图（优先用原图）

**一次调用裁完所有图**（同一张原图不要重复读取、重复调用）：

```bash
python <SKILL_DIR>/scripts/crop.py <原图> --outdir <项目>/images \
    --cuts "q1=120,340,520,260; q3=700,340,520,200"
# 拿不准像素用百分比；手机竖拍的图先 --rotate 90 转正
python <SKILL_DIR>/scripts/crop.py <原图> --rotate 90 --outdir <项目>/images \
    --cuts-pct "q1=0.08,0.45,0.42,0.22"
```

题目里写 `"stem_image_path": "<绝对路径>"`，生成器会拷进项目的 `images/`。
**生成器会把题图同时放到题目首页、解决问题页**。

原图太小/太糊/带涂改时才自己画：此时 `stem_image_path` 留空，在 `stem` 里用文字写清图形条件。

## 2. Word / PDF

```bash
python <SKILL_DIR>/../vendor/ppt-master/skills/ppt-master/scripts/source_to_md.py <文件>
```

读输出的 Markdown。PDF 的资源会落到 `images/` 并生成 `image_manifest.json`，可直接当 `stem_image_path`。
转出的公式要与常识校验（别把"12×5"变成"125"）。

## 3. 选题范围

默认全卷讲评。>20 题时主动建议"先讲错误率高的"，但**不自作主张砍题**。

## 4. 题型 → 讲评侧重

| 题型 | 侧重 |
|---|---|
| 填空/选择 | 讲"为什么是这个答案"，把干扰项错因讲透，易错点写满 |
| 判断 | 讲"改一个字就对了"，`mistakes` 写概念混淆 |
| 计算（口算/竖式/脱式/简算） | 讲运算顺序、凑整、进位退位；`solutions` 用 `lines` 脱式 |
| 操作/作图 | 讲步骤与规范（直角符号、标长度、用尺规）；必须配图 |
| 解决实际问题 | 六维度走全，`analysis` 四格写满 |
| 统计图表 | 讲"读图三看"：看标题、看单位、看每格代表多少 |

## 5. 写 JSON 前的最后检查

- [ ] 每题 `stem` 完整：数据、单位、问句齐全；`no` 与卷面一致；填了 `type`
- [ ] 有图的题都挂了 `stem_image_path`，且文件真实存在
- [ ] 一题多问已拆分
- [ ] `meta` 里卷名、年级、班级、日期齐了（不确定就合理推断，交付时说明）
