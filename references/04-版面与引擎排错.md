## 4. 标注样式（全部画在文字下方，不铺底、不遮挡）

| kind | 画法 |
|---|---|
| `cond` 条件 | 蓝色横线 + 序号字符 ①②③ |
| `ques` 问题 | 红色横线 |
| `key` 关键概念 | 黄色横线 |

圈画层是覆盖层，靠 `data-pptx-role="decoration"` 拿重叠豁免，否则会因与卡片 bounds 重叠被拒收。

## 5. 动画节奏

- 题目首页：点 1 下 → 条件与问题一次性全出（`entrance_appear`）；点 2 下 → 分析四格；点 3 下 → 易错点。
- 解题页：点一下出一个步骤，最后是"答"。变式页：点一下出一组提示/答案。
- deck 级默认 `none`，未列出的单元绝不动；全部 `on-click`，不自动播放。

## 7. SVG 契约硬约束（生成器已遵守，手写时照做）

- 根 `<svg>`：`xmlns`、`viewBox="0 0 1280 720"`、根级 `font-family`、`data-pptx-page-role`；禁止根级 `transform`。
- 每个可见顶层 `<g>` 要唯一 `id` + `data-pptx-bounds="x y w h"`；**普通内容组不得互相重叠**（容差 1px）。
- 重叠豁免：组带 `data-pptx-role` ∈ `background/chrome/decoration/footer/header/logo/page-number/watermark`。
- 多行写进同一个 `<text>` + `<tspan x dy>` 续行；不许用绝对 y 换行，不许把一段拆成兄弟 `<text>`。
- `& < >` 必须转义；禁止命名实体（`&nbsp;`），直接写 Unicode。
- 禁止：`<style>`、`class`、`<foreignObject>`、`<textPath>`、`<mask>`、SMIL、`<script>`。
- 图片：`<image href="../images/xxx.png">` 相对 **SVG 所在目录**解析（SVG 在 `svg_output/` 所以要回一级），
  必须有正 `width`/`height`；**图片必须和所在卡片写在同一个顶层组**，否则 bounds 重叠被判 blocking。
- 超链接：`<a href="#slide-3">` 包住 `<g>`，号是 1-based 最终页序，禁止嵌套 `<a>`。

`animations.json`：slide key = 文件名主干（带序号前缀、不带 `.svg`）；
`defaults.animation.effect` 必须是 `none`，只有显式命名的组才动。改完必须 validate。

## 8. 报错速查

| 报错 | 原因 → 处理 |
|---|---|
| `No SVG files found` | 路径相对 → 用绝对路径 |
| `data-pptx-bounds overlaps` | 顶层组几何重叠 → 分区或加 `role="decoration"` |
| `<text> ... exceeds <g> data-pptx-bounds` | 文字估宽超界 → 缩字号 / 放宽 bounds |
| `paragraph-like line run(s) split` | 多行拆成了兄弟 `<text>` → 合并成一个 + `<tspan>` |
| `animations.json references missing slide` | slide key 缺序号前缀或多带 `.svg` |
| `invalid image source ... empty/corrupt` | 解释器缺 Pillow → 用带 Pillow 的解释器（脚本会自动挑） |
| 导出跳过某页 | 该页有 blocking，看 `validation/svg_quality_report.json` 的 `categories.blocking.issues` |

不要绕过质量闸，不要手工改 `svg_output/*.svg` 当修 bug 的手段，不要动 `vendor/ppt-master`。
